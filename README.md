# President website

## Игра «Угадай шедевр» — памятка для бэкенда

Страница игры — `game.html`. Вся логика на фронте лежит в одном файле: `assets/js/game.js`.

### Суть игры

Пользователю по очереди показывают 5 картин. Про каждую он отвечает: это подлинник или картину нарисовала нейросеть. После каждого ответа появляется
окно с результатом. После пятой картины пользователь попадает в личный кабинет.

### Где лежат картины и тексты

- Список картин: `assets/json/game.json`
- Изображения: `assets/img/game/`

У каждой картины есть два файла: оригинал (`7.webp`) и подделка от нейросети (`7-fake.webp`). Номер в имени файла связывает их между собой.

Одна запись в `game.json` выглядит так:

```json
{ "isFake": false, "image": "7.webp", "name": "На&nbsp;берегу моря", "description": "Это картина Огюста Ренуара “На&nbsp;берегу моря”." }
```

- `isFake` — `true` для подделки, `false` для оригинала
- `image` — имя файла из `assets/img/game/`
- `name` — подпись под картиной. `<br>` переносит строку, `&nbsp;` не даёт короткому слову оторваться от следующего.
- `description` — текст в окне результата. У оригинала здесь автор и название, у всех подделок одна фраза: «Это полотно сгенерировала нейросеть.»

Чтобы добавить новую картину, положите оба файла в `assets/img/game/` и допишите две записи в `game.json`, одну для оригинала и одну для подделки.
Если у картины есть только один из двух файлов, игра её не возьмёт.

### Как проходит раунд

1. При открытии страницы игра выбирает 5 разных картин в случайном порядке: 2–3 подделки, остальные оригиналы. Оригинал и подделка одной картины в
   один раунд не попадают.
2. Пользователь нажимает «Подлинник» или «Проделки ИИ».
3. Открывается окно с результатом: картинка, заголовок «Абсолютно верно!» или «К сожалению, Вы ошиблись» и `description` картины.
4. Кнопка «Далее» закрывает окно и показывает следующую картину.
5. На пятой картине в окне появляется строка «Сегодня ты участвуешь в розыгрыше спецприза», а вместо «Далее» стоит ссылка «В личный кабинет»
   (`lk.html`). Строка про спецприз показывается всегда, независимо от числа верных ответов.

Количество картин в раунде и число подделок задаются в начале `game.js` (`ROUND_SIZE`, `MIN_FAKES`, `MAX_FAKES`).

### Что сохраняется в браузере

Сейчас всё хранится только в браузере пользователя, в `localStorage`. На сервер фронт ничего не отправляет.

**`president-game-progress`** — раунд, который ещё не закончен:

```json
{
  "images": ["14-fake.webp", "17.webp", "22-fake.webp", "18.webp", "19-fake.webp"],
  "answers": [{ "image": "14-fake.webp", "isFake": true, "answer": "original", "isCorrect": false }]
}
```

Эта запись обновляется после каждого ответа. Если пользователь перезагрузит страницу или уйдёт и вернётся, игра продолжится с той же картины. После
пятого ответа запись удаляется.

**`president-game-result`** — итог последнего законченного раунда:

```json
{
  "finishedAt": "2026-10-01T16:40:55.953Z",
  "total": 5,
  "correct": 2,
  "answers": [{ "image": "14-fake.webp", "isFake": true, "answer": "original", "isCorrect": false }]
}
```

- `answer` — что выбрал пользователь: `original` или `fake`
- `isCorrect` — угадал или нет
- `correct` — сколько ответов верных из `total`
